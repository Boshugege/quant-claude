# 公榜提交

因子赛道历次公榜提交的交付记录，共 43 个批次目录。**本目录是冻结的历史记录，不修改。**

## 批次目录里有什么

每个批次是一次交给团队成员上传比赛平台的一组因子。目录里通常有两个文件：

- `公榜提交说明_<批次>.md`（个别批次叫“上传说明”“补交说明”）：这一批交了哪些因子、每个因子的设计意图、本地五项、交付前做过的检查。
- `文件清单.md`：这一批上传的文件名，对应到 `因子代码/` 里的位置和 git blob。

比赛期间批次目录里放着可直接上传的 `.py`、`.ipynb` 和 zip。这些文件与 `因子代码/` 里的同名文件逐字节相同，公开仓库只保留 `因子代码/` 里的那一份，压缩包不随仓库发布。少数批次目录里还留着与 `因子代码/` 不同的文件（例如更早的版本或对照版本），原样保留。

批次说明是当时写的，其中的“待上传”“待出分”只反映当时的情况。
