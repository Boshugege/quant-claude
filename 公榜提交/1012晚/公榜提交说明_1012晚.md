## 每一对回答什么问题

1. **205 对 104**（相关 0.968，本地换手低约 0.13）：公榜上"同一个信号、只降换手"能加多少分。
   - 若加分 ≥ +0.03：换手还没饱和，低通线是真的。
   - 若加分接近 0：0.57 左右的换手在公榜已接近满分位，低通只是用 IC 换换手，应停止这条线。
2. **低通曲线** 525（0.85）→ 549（0.75）→ 544（0.70）→ 556（0.65）→ 543（0.55）：换手从 0.495 降到 0.366，找出公榜换手分位开始饱和的位置，以及最优 alpha。
3. **低通 × 中性化** 514 / 529 / 538（1.5 / 2.0 / 2.5 倍）：233→237 的"加大中性化力度在公榜加分"在低通下是否仍然成立。
4. **无低通的中性化曲线** 339 / 489 / 490 / 499（1.5 / 2.0 / 2.5 / 3.0 倍）：测中性化力度的最优点，以及 2.5 倍以上是否开始掉分。
