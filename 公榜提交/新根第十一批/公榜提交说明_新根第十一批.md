# 公榜提交 · 新根第十一批（2026-10-19 傍晚）：新方向「机制分组等风险合成」1622

## 为什么是新方向

以往五个方向的权重，要么是设计出来的整数（1610、1611），要么是优化器在 2020–22 上拟合的（1601、1603、1612），要么是树（1600、1617）。
1622 换了一种组合思路：**先按经济机制把分量分组，组内等权，组间按先验配权，没有任何从样本里拟合出来的权重。**它直接回应规则"因子应具有清晰的经济含义、可解释性和逻辑性，避免仅针对样本结果进行黑箱拟合"。

## 七个机制组

| 组（权重） | 分量与符号 | 反映的市场行为 |
|---|---|---|
| 锚点反转（0.5） | 490 头部 +、161 头部 + | 价格偏离近期锚点后回归。490 是多尺度短期反转阶梯（除以波动率），对应流动性提供者的补偿（Nagel 2012）；161 是相对一档中间价、挂单加权均价、VWAP 等锚点的偏离，在同伴组内比较 |
| 流动性提供（0.5／6） | 近 60／90 分钟上涨分钟成交量占比 −、量价同向 − | 买压集中推高的价格随后回吐（Campbell–Grossman–Wang 1993） |
| 知情交易（0.5／6） | 聪明钱 +、当日大单方向 −、近 5 日大单方向 −、近 5 日单笔额离散度 + | 低量高冲击分钟的价格更有信息；大单推动的短期方向多为流动性需求，随后回吐 |
| 价格摩擦（0.5／6） | 零收益分钟占比 + | 价格黏滞、跳价约束大的股票要求流动性溢价 |
| 季节性（0.5／6） | 同时段季节性 +、收盘段季节性 + | 同一时段的收益在日间延续（Heston–Korajczyk–Sadka 2010）；尾盘由收盘集合竞价主导，有稳定习惯 |
| 收盘行为（0.5／6） | 收盘位置 +、前日收盘竞价冲击 + | 收盘定价压力的回归 |
| 分布形态（0.5／6） | 日内已实现峰度 −、近 5 日已实现偏度 − | 彩票型偏好推高尾部股票，随后回吐 |

合成方式：每个分量先做截面排名并乘以符号；组内取平均，再逐截面标准化；最后按组权重相加。近 5 日的两个成交笔数根用平台安全写法，与第十批相同。
