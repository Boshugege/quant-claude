## 每一对回答什么问题

1. **1060 + 1061 夹 490（中性化峰位）**：公榜已知 1.5× 0.78491 → 2.0× 0.79739 → **2.5× 0.80377** → 3.0× 0.79855。补上 2.25× 与 2.75× 可以把"峰是单点还是平台"以及峰位到底在 2.5 的哪一侧定死。本地这一轴是纯单调的（IC 随倍数单调下降、换手单调下降，两年 z 全部同号且 8–11），**本地没有最优点可言**，只能靠公榜定；这两个点就是为此花的。
2. **1062 + 1065（低通 0.75 之上还有没有）**：公榜在 0.55–0.75 段是单调上升的（0.75094 → 0.78055 → 0.79100 → 0.80029），本地同段 IC 也单调（0.0693 → 0.0723 → 0.0736 → 0.0746），本地 IC 每 +0.001 对应公榜约 +0.009。**按这个局部斜率外推，0.80／0.85 应在 0.808–0.812（⚠ 外推）**，也就是说这一对有可能直接越过现在最高的 490（0.80377）和 237（0.80441）。这是本批最重要的一对。
3. **1066 + 1067（挂单分量权重）**：本地 0.05–0.15 是死轴（配对 |z|<4，1066 的微弱 IC 优势被 IC_IR 下降抵消），与 104 的相关也几乎不动（1066 剔 09:30 后 0.8408、1067 0.8378、549 本身 0.8403）。这一对的用途是把「挂单盘口这一路信息（485 单独成因子时公榜 0.77358）在头部里到底出了多少力」钉住：如果公榜上 1066／1067 与 549 完全同分，说明盘口分量在头部已无边际贡献，线 C 可以收口；如果分开，说明权重还有残余空间。
