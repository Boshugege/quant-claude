# 因子代码

因子赛道写过的全部因子，按编号平铺在本目录。共 1390 个编号：每个编号有一个 `.py`，其中 571 个另有同名 `.ipynb`；另有两个模板 `_F_multi_template.py`、`_K_micro_template.py`。

**本目录是冻结的交付记录，文件不修改。** 修复或改动一律写成新编号的新文件。

## 文件形式

- `.py`：完整的 `main(datasources, start_date, end_date)`，返回 `date / instrument / factor` 三列；末尾带 `if __name__ == "__main__":` 平台自测块。
- `.ipynb`：同一份代码去掉自测块，只有一个代码单元，可直接上传比赛平台。
- 全部代码依赖平台模块 `dai`、`bigmodule` 和平台数据表，**只能在比赛平台运行**。出现 `ModuleNotFoundError: No module named 'dai'` 不是代码错误。
- 早期文件名带“得分0.xxxxx”，是当时的公榜分数；公榜分数是相对分，后来会变，以 `因子得分总表.md` 为准。
- 文件名最长超过 200 字节。个别文件系统不支持；git 列文件时加 `-c core.quotepath=false`。

## notebook

- 01–189 号大多有 notebook；495 号之后的批量候选大多只有 `.py`。
- 1600–1672 号的文件内嵌树模型，单个 2 MB 以上。公开仓库只为 1617、1626、1669、1670 保留了内嵌树模型的 notebook，其余可以从 `.py` 重新生成：

```bash
python3 因子实验/make_ipynb.py <文件.py>            # 输出写在 .py 旁边
python3 因子实验/check_ipynb.py <文件.ipynb>        # 检查被调用的顶层函数都有定义
```

重新生成时请把 `.py` 复制到仓库外再运行，不要往本目录添加文件。
