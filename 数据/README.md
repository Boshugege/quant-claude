# 数据目录

本仓库不发布任何数据。`数据/` 下只有本说明和一份平台探测 notebook（输出已清空）。行情文件、官方表的本地副本、代码对照表都不在仓库里，`.gitignore` 也不收 `*.parquet` 和 `*.feather`。

本文件说明代码默认到哪里找数据，以及缺少某一项时哪些功能不能用。

## 目录约定

| 路径 | 内容 | 来源 | 随仓库发布 |
|---|---|---|---|
| `数据/raw_bar30m/cpt_jyc_2026_e2e_bar30m/YYYYMM.0.feather` | 30 分钟行情，2020-01 至 2024-12，每月一个文件 | 主办方公开下载 | 否 |
| `数据/raw_bar1m/cpt_jyc_2026_e2e_bar1m/YYYYMM.0.feather` | 1 分钟行情，同一区间 | 主办方公开下载 | 否 |
| `数据/exposure/exposure_YYYY.parquet` | 官方风格暴露表 `cpt_jyc_2026_exposure` 按年保存的副本（结构见 `e2e/reports/09_官方风格暴露表.md`） | 比赛平台 | 否 |
| `数据/exposure/id_map.csv` | 本地匿名代码与真实代码的对应表 | — | 否 |
| `数据/平台探测/*.parquet` | 平台探测的产出：官方标签片段、因子在平台上的取值、平台处理后的因子值 | 比赛平台 | 否 |
| `数据/平台探测/test2.ipynb` | 平台探测 01 的 notebook 版本（与 `e2e/平台探测/probe_01_标签与评测.py` 内容相同），输出已清空 | 本仓库 | 是 |

## 行情数据

主办方公开的下载地址：

- 30 分钟行情：<https://bigquant-public-download.tos-cn-shanghai.volces.com/jyc2026/cpt_jyc_2026_e2e_bar30m.tar.gz>
- 1 分钟行情：<https://bigquant-public-download.tos-cn-shanghai.volces.com/jyc2026/cpt_jyc_2026_e2e_bar1m.tar.gz>

这些地址由主办方维护，可能失效；数据的使用以主办方的规定为准。解压后按上表的路径放置，不要把行情文件提交进仓库。压缩包里文件的权限位不规范，解压后需要执行一次 `chmod 644`。

这份行情只有整数 `instrument_id`，没有股票代码。本仓库的代码把它写成 `ID` 加 4 位数字的伪代码（如 `ID0001`），只用来在本地保持前后一致。数据字段、单位和标签口径见 `e2e/交接文档.md` 第 3 节与 `本地评分系统说明.md` 第二、三节。

## 官方风格暴露表与代码对应表

官方风格暴露表按真实代码索引，本地行情使用主办方的匿名代码，两者的对应表（`id_map.csv`）不随仓库发布，暴露表的本地副本也不随仓库发布。

缺少这两类文件时：

- 本地评估不能按平台口径剔除官方风格和行业。`工具/本地评分/localeval.py`、`分享/jyc_local_eval/localeval.py` 会给出提示并退回不剔除风格，五项指标仍能算出，但与平台口径不一致。
- `e2e/scripts/train_local.py` 的逐轮 `[val]` 只报原始口径。
- 直接读取对应表的脚本会在读文件时报错，包括 `工具/评分机/` 的数据预处理与评分、`e2e/scripts/` 下的平台核对脚本、`因子实验/` 下读取 `id_map.csv` 的脚本。

提交到平台的因子代码和端到端三件套在平台上运行，读的是平台表，不依赖这两类本地文件。端到端训练脚本里只有本地诊断选项 `TRAIN_NEUTRAL = "official"` 会读它们，默认不启用。

## 平台探测数据

`e2e/平台探测/` 下的两个脚本在比赛平台上运行，产出的 Parquet 文件原先放在 `数据/平台探测/`，用于核对标签定义和评测口径；这些文件不随仓库发布。核对的结论记录在 `e2e/reports/12_官方标签与09点30缺陷.md`。
