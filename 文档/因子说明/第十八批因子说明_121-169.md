## 2. 口径警告：7 截面与 8 截面不可比

- 不补 09:30 的版本（104、108–112、120）在 09:30 截面恒为 0，评分机会把常数截面剔除，
  于是它只按 7 个截面算 IC/IC_IR，数值天然更高：104 号为 0.909、120 号为 0.936，而补了 09:30 的
  同结构版本只有 0.796 / 0.823。**所以只能拿同为补齐的版本互相比较**，跨版本比较会得出错误结论。
- 用户判定必须补 09:30（否则与真实榜单口径不一致），本批所有候选都补；120 号就是留给用户在公榜上
  验证「补/不补」差异的对照提交。

## 3. 结论与建议提交顺序

1. **128（软同伴 k=200、3 次方加权）**：本轮代理分最高（0.834），比 114（0.823）高一档；
   140（k=400、4 次方）为 0.830，说明同伴「越软越好」在 k≈200–400 附近已经到顶。
2. **119（六尺度）**：换手百分位 0.70 是本轮最好的一档，适合放进任何需要压换手的组合。
3. **114 / 117 / 126 / 130**：都在 0.82 附近，可作为备选提交。
4. 其余分钟级微结构附加项（122/124/127 等）均略低于底座，属于「信息被阶梯覆盖」的情况，
   保留在文档里备查，不必优先提交。

## 4. 本轮放弃/暂缓的方向（含失败记录）
