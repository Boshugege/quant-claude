# 决赛材料

本目录收录两个赛道的决赛材料：正式提交给主办方的文件，以及撰写这些文件时整理的四篇底稿。

## 最终成绩

| 赛道 | 队名 | 最终作品 | 公榜 | 私榜 |
|---|---|---|---|---|
| 因子赛道 | fx战队 | 因子 1669（私榜候选 1669、1670） | 第二 | 总榜第二 |
| 端到端赛道 | fx二号机 | 模型 E21 | 第四 | 第六 |

## 目录

| 位置 | 内容 |
|---|---|
| `提交材料/因子赛道/`、`提交材料/端到端赛道/` | 决赛前提交给主办方的材料：展示幻灯片、策略研究报告、AI 工具使用说明（PDF 与 LaTeX 源文件），以及数据图和作图脚本。各自的 `README.md` 说明文件清单与编译方法 |
| `提交材料/_style/` | 报告与幻灯片的 LaTeX 模板和早期版式样张。样张（`*_demo`）的标题和内容是定稿之前的旧版本，不代表最终结果 |
| `因子赛道/01_开发历程全记录.md`、`端到端赛道/01_开发历程全记录.md` | 开发历程：按时间记录的方向、实验、否决与修正 |
| `因子赛道/02_最终因子1669与1670详解.md`、`端到端赛道/02_最终模型E21详解.md` | 最终作品详解：组成、输入、目标、组合方式与可解释性 |
| `因子赛道/03_信号质量_统计检验与稳定性.md`、`端到端赛道/03_信号质量_统计检验与稳定性.md` | 信号质量：五项指标、统计检验、样本外稳定性、公榜与私榜的差异 |
| `因子赛道/04_复现说明与数据依赖声明.md`、`端到端赛道/04_复现说明与数据依赖声明.md` | 复现说明：冻结文件、构建与训练步骤、环境依赖、数据来源 |

## 阅读说明

- 四篇底稿与 `提交材料/` 不一致时，以 `提交材料/` 为准。底稿成稿于 2026-11-10 至 11-11，公开前做过文字整理；因子赛道私榜名次已按 2026-11-13 更新后的最终结果改为总榜第二。
- 底稿中的 git 提交号指私有开发仓库的历史，公开仓库无法按提交号检出；标为「内部……（未公开）」「项目记忆」「原料笔记」「素材笔记」的出处不随公开仓库发布。
- 答辩准备笔记和讲稿不在公开仓库中。
- 全仓库的复现入口见 `文档/复现与消融指南.md`。
