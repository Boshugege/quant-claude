## 编译

在本目录下用 `xelatex` 编译，源文件引用 `../_style/` 下的模板和 `figures/` 下的图：

```bash
# 策略研究报告与 AI 工具使用说明：各编译三遍（目录、交叉引用和跨页表格需要多遍才能稳定）
xelatex 因子赛道_策略研究报告.tex
xelatex 因子赛道_策略研究报告.tex
xelatex 因子赛道_策略研究报告.tex

xelatex 因子赛道_AI工具使用说明.tex
xelatex 因子赛道_AI工具使用说明.tex
xelatex 因子赛道_AI工具使用说明.tex

# 展示幻灯片：编译两遍（页面上的定位图形需要第二遍）
xelatex 因子赛道_决赛展示.tex
xelatex 因子赛道_决赛展示.tex
```

模板使用微软雅黑、宋体-简（Songti SC）和 Times New Roman 三种字体。微软雅黑的字体文件路径写在 `../_style/report_preamble.tex` 与 `../_style/slides_preamble.tex` 的 `\yhpath` 中，换机器编译时按本机路径修改。

数据图可以用 `python3 figures/make_figures.py` 重新生成，所需数据和每张图的数字出处见 `figures/图表清单.md`。
