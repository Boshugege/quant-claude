| 数据 | 来源 | 放置位置（需自行准备） | 用途 |

## 二、因子赛道：1669／1670 怎样从头生成

### 2.1 最终文件
- `因子代码/1669_*`、`因子代码/1670_*`：1669（1617 底座，β 1.1）、1670（1626 底座，β 0.8）的 `.ipynb`／`.py`。在比赛平台上原样运行即可复现分数。
- `公榜提交/新根第二十九批/`：这一批的提交说明和 `文件清单.md`。当时上传的文件与 `因子代码/` 里的同名文件逐字节相同，仓库只保留 `因子代码/` 里的那一份。
- `因子代码/` 里只有 1617、1626、1669、1670 保留了内嵌树模型的 `.ipynb`；其他内嵌树模型的 notebook 可以用 `python3 因子实验/make_ipynb.py <文件.py>` 从 `.py` 重新生成。

### 2.2 生成链（每一步都是可单独消融的增量）
```bash
# 底座：1617（树拟合 2020–22）／1626（拟合 2020–24）的代码在 因子代码/1617_*、1626_*，树模型 JSON 在 因子实验/models/h2_avg16*.json
# 1669 = 1617 底座 + 委托规模比 q(0.3) + 14 个附加项 + 缓冲带前风格剔除 + 最小抬升缓冲带 β 1.1
ADDS="s35_of_l10_rel:0.15,s20_ql_end:0.10,s16_l10_clv:0.10,s37_auc_m20:0.20,s37_auc_m5:0.20,s40_q14_s1:-0.20,s40_q14_end:-0.20,s40_of14:-0.20,s5_c_abnvol@1430:-0.20,s18_abnamt_day@1430:-0.20,s25_ts_sv_l10:0.10,s16_l10_ret:0.10,s6_amt_5d20d:0.10,s10_am_drift:0.10"
python3 因子实验/build_1664.py 1669 "<名字>" 1.1 0.6 "$ADDS" 0.3          # 1670：BASE=1626 …… 0.8
python3 因子实验/make_ipynb.py 因子代码/1669_<名字>.py && python3 因子实验/check_ipynb.py 因子代码/1669_<名字>.ipynb
```
- `build_1649.py`（底座 + q + 最小抬升缓冲带）→ `build_1653.py`（嵌入附加项的平台脚本，来自 `因子实验/s1_sqlgen.py`）→ `build_1664.py`（缓冲带之前插入风格剔除）。
- 附加项的含义、方向、权重来历：`文档/方向登记表.md` 5.1x～5.1ad；分数：`因子得分总表.md`。

### 2.3 树底座的重训（需要因子引擎）
- 代码：`因子实验/h2_robust.py`（拟合）、`h2_stack.py`（直方图 GBDT）、`merge_gbdt.py`（16 个配置合并）、`c50_tree_explain.py`（分裂重要性、单特征敏感度、时段交互）。
- 16 个配置与种子：`因子得分总表.md`「树：T1 全量拟合 → 1626」；驱动脚本原文见 `因子实验/过程记录/macstudio引擎/驱动脚本/`、日志在同目录 `日志/`（日志目录里的中间树模型 JSON 未随仓库公开，最终用到的树模型在 `因子实验/models/`）。
- 引擎需要的面板由评分机的 `prepare_data.py` 从原始数据生成，放在评分机的 `store/core`，可重建。

### 2.4 本地评分（评分机）
- 代码：`工具/评分机/`（与比赛期间线上运行的 2.5.3 版一致）。比赛期间线上的容器配置快照未随仓库公开，仓库里的 `jyc-scorer.container` 是模板。
- 比赛期间的评分机服务已**停用**（2026-10-31）。要自己运行，按 `工具/评分机/README.md` 第 5 节部署；它需要 `data/`（原始输入）和 `store/`（可用 `prepare_data.py` 重建）。服务没有身份认证，并且会执行上传的代码，只能监听本机地址。
- 轻量版（不起服务）：`工具/本地评分/localeval.py`，与评分机同口径。
- 历史上全部评分任务（共 6600 个；索引表有 13197 行，因为在线目录和硬盘归档各列了一次，要按 job_id 去重）的名字、区间、五项和逐年五项：`工具/评分机/任务索引/评分机全部任务索引_2026-10-31.csv`（因子值本身已清理，可按任务名在 `s1_sqlgen.py`／构建脚本里重新生成）。
- `因子实验/` 里的许多脚本（包括下面的 `c105j_turnover.py`）读取评分机的任务目录，或调用评分机在 `127.0.0.1:46220` 上的接口。没有运行中的评分机和对应的值任务时，这些脚本不能直接运行，要先重建数据、启动评分机、重新提交底座的值任务。

### 2.5 常用消融入口
| 想看的增量 | 怎么做 |
|---|---|
| 树对线性组合 | 评分机跑 `因子代码/1610_*`（线性）对 `1617_*`（树），2023–24 是树的样本外 |
| 每个附加项 | `因子实验/c105j_turnover.py`：`ADD=` 去掉某一项，其余不变（输入是底座的值任务） |

| 树的可解释性 | `c50_tree_explain.py <树 JSON>`；结论见 `文档/决赛材料/因子赛道/02_最终因子1669与1670详解.md` |
