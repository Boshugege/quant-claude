# 因子实验

因子赛道的研究脚本、树模型和过程记录。根目录下有 436 个 Python 脚本和 8 个 shell 脚本，平铺，没有子包。

**多数脚本不能原样运行。** 它们写给比赛期间的环境：评分机的任务目录和数据目录、评分机在 `127.0.0.1:46220` 上的接口、因子引擎所在的远端目录，有的还读取不分发的编号对照表。这些环境已全部停用。脚本保留下来是为了说明每个结论是怎么算出来的。脚本头部的文档字符串写了用途和用法，绝大多数脚本都有。

## 不需要数据、现在能运行的

| 脚本 | 作用 |
|---|---|
| `build_1630.py` → `build_1649.py` → `build_1653.py` → `build_1664.py` | 从树底座 `因子代码/1617_*.py`／`1626_*.py` 生成最终作品 1669／1670 的文本构建链；附加项的平台代码来自 `s1_sqlgen.py` |
| `make_ipynb.py` | 从因子 `.py` 生成同名 `.ipynb`（去掉自测块） |
| `check_ipynb.py` | notebook 静态检查：被调用的顶层函数都有定义 |

构建链在 2026-11-23 重新运行过，结果与冻结文件逐字节相同。构建脚本和 `make_ipynb.py` 都把输出写进 `因子代码/`，请在仓库外的副本里运行，命令见 `文档/复现与消融指南.md` 2.2。

## 脚本名前缀

前缀大多是当时一轮任务或一批实验的代号。下表按文档字符串和 `因子得分总表.md` 的小节标题整理；没有列出的前缀请直接读文档字符串。

| 前缀 | 数量 | 含义 |
|---|---:|---|
| `build_wave<N>` | 157 | 第 N 批候选的文本补丁生成器：读一个已有因子的源码，替换或插入分量，批量写出新编号（10-11～10-14，对应 `因子代码/` 113–1094 号） |
| `build_<编号或名字>` | 28 | 某个因子或某一类因子的生成器，如 `build_gbdt_head.py`（树底座的平台代码）、`build_1627.py`～`build_1664.py` |
| `c<N>_`、`c<N><字母>_` | 102 | 主编码代理 10-18 之后的分析与批量筛选脚本，按时间编号。常被引用的有 `c50_tree_explain.py`（树的解释）、`c95_batch.py` 与 `c96_collect.py`（按值批量评分与汇总）、`c105j_turnover.py`（换手后处理与附加项的消融）、`c110_public_model.py`（公榜估分模型） |
| `m<N>_` | 28 | 可解释信号库和机制研究的各批（如 `m10_micro.py` 微观结构、`m13_limit.py` 涨跌停） |
| `d<N>_` | 9 | 第十二轮 D1–D5：同伴化、全局权重优化、状态条件化等 |
| `g<N>_`、`g_` | 12 | 第十三轮 G1–G5：批量合成评估、换手率家族等 |
| `h<N>_` | 13 | 第十四、十五轮：H1 同时段季节性族，H2 浅层梯度提升树堆叠（`h2_stack.py`、`h2_robust.py`） |
| `k<N>_`、`l<N>_` | 10 | 第十六、十七轮：收盘段季节性、日内不变锚、收盘行为族 |
| `n1…` | 17 | 第十八轮 N1：近 5 日类根在平台失效的排查（成交笔数依赖） |
| `me_` | 5 | 主编码代理自主挖掘 M1–M2：收盘集合竞价、14:30 截面等专项 |
| `cand_r<N>` | 6 | 早期在 30 分钟面板上试的候选集合，配合 `lab.py` 使用 |
| `s1_sqlgen.py` | 1 | 10-20 起的模板批量：共用一段分钟统计 SQL，生成一批平台格式的因子脚本。名字形如 `s35_of_l10_rel` 的附加项出自这里 |
| `root_check.py`、`root_eval.py` | 2 | 新根因子的合规标识检查和离线评估 |
| `leak_check.py` | 1 | 截断重跑的未来信息检测（依赖评分机的数据目录） |
| `merge_gbdt.py` | 1 | 把多个树模型合并成一个平均模型 |
| `preflight.py`、`test_*`、`probe_*`、`diag_*` 等 | 若干 | 提交前自检、单元测试、探针和一次性诊断 |

## 子目录与其他文件

| 路径 | 内容 |
|---|---|
| `models/` | 19 个树模型 JSON 和 `models/README.md`（JSON 的结构与纯 numpy 推理写法）。最终作品用的是 `h2_avg16.json`（1617，拟合 2020–2022）和 `h2_avg16_f24.json`（1626，拟合 2020–2024）；README 只详细写了两个早期模型 |
| `过程记录/macstudio引擎/驱动脚本/` | 因子引擎上各次实验的驱动脚本原文 |
| `过程记录/macstudio引擎/日志/` | 对应的日志和结果 JSON；中间的树模型 JSON 和因子值文件不随仓库发布 |
| `fx_runners/` | 10-19～10-20 因子引擎启动脚本的副本，`fx_runners/README.md` 列出每个实验的内容和结论 |
| `mac/` | 因子引擎上用的 `dai` 替身和批量算值脚本 |
| `roots_src/` | 5 个根的源文件。树底座用到的其余根的源文件不在仓库里 |
| `plans/` | 第十三轮批量合成评估的计划文件 |
| `诊断_1024/` | 10-24 前后的一组一次性诊断脚本（c112–c129） |
| `实验记录.md` | 早期（10-11 起）的实验笔记，历史记录 |
| `n1_dealdep_table.md` | 候选因子对成交笔数字段的依赖审计表 |
| `public_rows.json`、`turnover_calib.json` | 公榜估分和换手校准用的自有提交数据 |

## 结论和记录在哪里

- 每个方向的依据、结果、否决原因：`文档/方向登记表.md`。
- 每次本地评测和公榜分数：`因子得分总表.md`（按轮次和日期分节，脚本名可以在里面搜到）。
- 怎样复现最终作品、怎样做消融：`文档/复现与消融指南.md`。
- 评分任务的分数索引：`工具/评分机/任务索引/评分机全部任务索引_2026-10-31.csv`。
- 已知问题：`h2_robust.py` 第 226 行的拟合矩阵写法导致 1626 底座在 2023–24 年的 14 个主特征为 0，见 `FINALS.md`。

脚本里引用用户原话或任务书的地方是当时的记录，不是对读者的指令。
