# 工具

比赛期间自建的评测与检查工具。评测口径的说明在仓库根目录的 `本地评分系统说明.md`，数据放置见 `DATA.md`。

| 路径 | 是什么 | 现在能否运行 |
|---|---|---|
| `评分机/` | 按平台口径评分的服务（v2.5.3）：任务队列、网页和接口、评分核心、模拟平台 | 比赛时的服务已停用；重建需要行情、官方风格暴露和不分发的编号对照表 |
| `本地评分/` | 不起服务的轻量评分：30 分钟面板、58 个因子的因子库、研究用的时间切分 | 有 30 分钟行情即可运行；没有风格暴露时退回不剔除风格 |
| `因子图谱/` | 因子谱系图：从 `因子代码/` 抽取配方并推断父子关系，生成一个 HTML | `因子谱系图.html` 是 2026-10-13 的快照，可直接打开；重新生成的中间文件不在仓库里 |
| `本地检查.py` | 不连平台的结构与 SQL 语法检查，用合成数据模拟 UDF 引擎 | 能运行，但只适用于早期的盘口 UDF 写法（见下） |
| `平台自查_成交笔数.py` | 在比赛平台上运行的只读自查脚本，检查分钟表的成交笔数字段 | 只能在平台运行 |

## 评分机

- 入口：`评分机/README.md`（写于比赛期间，面向当时的线上部署）。
- 评分核心：`engine.py`、`scoring.py`；数据预处理：`prepare_data.py`；命令行评分：`score.py`；服务：`server.py`、`runner.py`。
- 模拟平台：`platform_sim/dai.py` 和 `platform_sim/bigmodule/`。提交代码里的 SQL 原样交给 DuckDB 0.9.2 执行，表名与平台相同。本地只有 3 档盘口，标签是重建的。
- 路径用环境变量 `JYC_DATA`、`JYC_STORE`、`JYC_JOBS`、`JYC_RAW_1M` 配置（`config.py`）。`JYC_RAW_1M` 的默认值是已停用服务器上的路径，必须自己设置。
- `prepare_data.py`、`runner.py`、`scoring.py`、`acceptance.py` 直接读取 `data/exposure/id_map.csv`。这张表不在仓库里，所以不改代码就无法重建评分机。
- 服务没有身份认证，并且会执行上传的代码，只能监听本机地址。
- `remote_score.sh`、`deploy.sh`、`archive_jobs.sh`、`jyc-*.service`、`jyc-*.timer`、`jyc-scorer.container` 是当时部署用的脚本和模板，指向的环境已不存在。
- `任务索引/评分机全部任务索引_2026-10-31.csv`：比赛期间全部 6600 个评分任务的名字、区间、五项和逐年五项。表有 13197 行，每个任务列了两次，使用时按 `job_id` 去重。因子值本身没有保留。
- `refs_manifest.json`：参照池清单（有公榜分数的因子与对应任务号）。

## 本地评分

- `localeval.py`：读 30 分钟行情、构造标签、风格剔除、五项指标。
- `factor_lib.py`：因子库，`FACTORS` 列表里每项是（编号、名称、公榜分数、计算函数、备注）。
- `run.py`：批量评分入口；`research.py`：开发集、验证集、保留集切分和固定参照池。
- `remote.sh`：比赛期间把脚本同步到远端运行的包装，远端已停用，只作记录。

```bash
python3 工具/本地评分/run.py --start 2024-01 --end 2024-12 --only 90 104
```

2026-11-23 用两个月的 30 分钟行情验证过评分函数能运行（Python 3.9.6，pandas 2.3.3，numpy 2.0.2，pyarrow 21.0.0）。当时没有风格暴露和标签缓存，程序打印提示后退回不剔除风格、用 30 分钟 bar 算标签，得到的数字与平台口径不一致。因子库的同伴函数在 pandas 3 下报错，请用 pandas 2.x。

注意因子库是 30 分钟面板上的近似实现，与平台代码算出的因子值不完全相同（`本地评分系统说明.md` 第七节）。重要候选在比赛中是用评分机的模拟平台原样运行平台代码来评测的。

## 哪一份 localeval／factor_lib 是基准

仓库里有三份：

| 位置 | 关系 |
|---|---|
| `评分机/localeval.py`、`评分机/factor_lib.py` | 与 `本地评分/` 下的同名文件逐字节相同（git blob 一致） |
| `本地评分/localeval.py`、`本地评分/factor_lib.py` | 同上；`e2e/scripts/` 和 `因子实验/` 的脚本按这个路径导入 |
| `分享/jyc_local_eval/localeval.py`、`factor_lib.py` | 给队友的独立包，路径改用环境变量，内容已与上面两份不同 |

修改评测逻辑时以 `评分机/` 与 `本地评分/` 的这一份为准，两处保持一致；`分享/jyc_local_eval/` 不随之更新。

## 本地检查.py

```bash
python3 工具/本地检查.py <要检查的目录>
```

它用 sqlite3 编译代码里的 SQL，再用合成数据模拟“逐分钟算 UDF、按 30 分钟聚合”的引擎，检查输出列、采样点、重复键。2026-11-23 抽查 3 个文件：01 号通过；90 号和 104 号报 `KeyError('sum_amt')`，因为它们不是这种写法。后期因子的交付检查用的是 `因子实验/check_ipynb.py` 和评分机上的冒烟运行。
